# Scenario 1 : Employee Pay Calculator

## Description

This project is a simple Python program that calculates an employee's weekly wage. It calculates normal pay for up to 40 hours worked and applies an overtime rate of 1.5 times the normal hourly wage for any hours worked over 40. The program also checks that the number of hours entered does not exceed 168 hours in one week.

## Features

* Accepts the employee's hourly wage.
* Accepts the number of hours worked in a week.
* Calculates normal pay.
* Calculates overtime pay at 1.5× the hourly wage.
* Rejects values greater than 168 hours worked in a week.

## Requirements

* Python 3.x

No additional libraries or third-party modules are required.

## How to Run

1. Open the project in PyCharm or another Python IDE.
2. Run the Python file.
3. Enter your hourly wage when prompted.
4. Enter the number of hours worked.
5. The program will display the total weekly wage.

## Limitations

* The program does not currently validate negative input values.
* If more than 168 hours are entered, the program displays an error message and exits.
* User input must be numeric.
